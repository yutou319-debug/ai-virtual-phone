# 单次云回复提交错误（待发布）

HTTP 413 表示提交请求过大，不能一概提示“重新部署个人离线推送”。
本次为 413 单独提示减少历史/图片数量、关闭图片细节增强；其他 HTTP 错误显示状态码，网络失败单独说明。
提交失败不轮询不存在的任务，不自动缩减内容后重试，也不切换手机模型，保留单次执行保护。

提示词、历史和图片共同计入请求大小；减少图片只是排查手段，不保证文本过大时有效。
本次不提高云端快照大小上限、不删除历史或图片，也不部署生产。

验证：`node scripts/check-single-reply-executor.cjs` 包含 413 只提交一次、不导入任务和正确错误分类的模拟检查。
