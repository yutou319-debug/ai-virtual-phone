# MiniMax 中文语音动作

语音条、语音/视频通话和试听共用 `synthesizeSpeech`，会把独立标记 `[轻笑]`、`【轻笑】`、`（轻笑）`、`(轻笑)` 转换为 MiniMax 2.8 的 `(chuckle)`。同样支持笑声、叹气、换气、吸气、呼气及对应英文标签。普通叙述和未知括号内容保持原样；旧版 MiniMax 和 OpenAI 会去掉这些已识别的标记，避免朗读动作名称。

在角色提示中可添加：

> 发语音或通话时，可以偶尔在台词中使用【轻笑】、【叹气】、【换气】、【吸气】或【呼气】表示声音动作；仅在合适的位置使用，避免每句都加。语音条的标记要放在语音正文内。

模型使用 `speech-2.8-turbo` 或 `speech-2.8-hd`，沿用现有音色。音色的实际表现需试听确认。此功能不包含外部音效素材、亲吻音效或音轨混合，也没有修改角色提示或自动添加声音动作。

语音消息已有落库音频缓存。本次额外增加同页面会话内的共同合成缓存（最多 32 项、16 MiB）及在途请求去重；文本、模型、音色、语速、音调、语言、情绪、请求地址和凭证不同，不共用缓存。不持久化凭证。页面重载会清除此缓存，通话语音不保证跨重载复用。失败不自动重试；手动重试仍可能计费。供应商计费和跨设备并发不由此缓存控制。

验证：Node 24 下运行 `node scripts/check-speech-expression.cjs`，使用模拟接口，不发送收费请求。完整生产构建和真实音色试听尚需部署环境验证。
