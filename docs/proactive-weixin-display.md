# 主动微信消息过滤与表情包（待发布）

定时/每日等主动消息使用 `sendProactiveText`，此前直接按空行分段发文字，绕过普通微信回复的显示清理和媒体解析。因此内心、数值状态、`[表情包:名称]` 会原样发送。

现在主动发送先清理内心、状态栏、数值状态和 think 块（未闭合的隐藏块也按隐藏处理），按原位置拆成文字和已配置的表情包图片；不存在的表情包不发送假图片，媒体关闭时不发送控制标记。不调用生图、语音或第二次模型生成。

微信只接收显示内容，Float 同步仍保存一份原始完整回复，因此原来的内心卡片、表情包和上下文保留。mirrorOnly 路径不重复存历史。业务拒绝继续使用已有错误码校验，不自动重发或重新生成。

核心协议升级到 7，未来部署时拒绝旧桶代码覆盖修复。当前仅保存 GitHub 分支，不合并 main，不更新 Netlify 或 Supabase，不补发历史消息。

验证：`scripts/check-proactive-weixin-media.cjs` 使用截图同格式的模拟回复，执行实际清理、拆分和发送分派函数；测试文字/图片顺序、隐藏信息不外发、原始历史仅保留一次、缺失资源、媒体关闭、未闭合隐藏标签、微信拒绝。结合既有每日投递、主动镜像、通知独立、语音转写、表情包和并发合并回归检查。所有测试均为模拟，无真实发送或付费 API 调用。
