# Float 内持续通话

第一版支持单聊语音和视频通话。通话由桌面常驻层持有，可在 Float 内回会话列表、桌面或朋友圈；最小化继续计时、监听和播放，不重新发起通话。小窗可拖动、点击恢复或直接挂断。同一页面最多一个全局单聊通话；群聊通话仍沿用原实现，不包含本次持续通话功能。

## 使用

发起单聊通话，接通后点左上角返回箭头缩小，再在 Float 内切换页面。点击小窗恢复。麦克风开启时，最小化仍会监听；需要静音请先在完整通话界面关闭麦克风，或直接挂断。它不是 iOS 系统后台通话：切到微信、锁屏或刷新页面后，不保证持续监听/播放，刷新结束通话。

自动找话题默认每次新通话关闭。在通话界面开启，默认安静 3 分钟主动说话，每次通话最多 5 次；可选 2/3/5/10 分钟，最多 1/3/5/10 次。仅在页面可见、通话空闲且没有排队消息时触发。用户说话重新等待完整间隔；切出 Float 暂停计时，回来重新等待，不补发错过的任务。开关切换不清零已用次数。空回复、生成失败或语音失败停止自动搭话，失败尝试仍计入上限。

主动搭话会调用聊天模型，播放语音还会调用现有语音服务。等待计时本身不调用模型。继续沿用 MiniMax 的中文配置、音色、语速以及已实现的语音缓存与音效。

## 请求和费用边界

通话内每一轮模型生成、语音合成和播放整体串行处理。忙碌时发送的文字最多排队 5 条，队列满时保留输入；挂断立即清空队列、取消在途聊天请求和播放。语音识别同一轮 final/end 只提交一次。普通聊天对同一会话的生成与冷场重连在通话期间暂停，通话请求不进入普通聊天的个人云生成分支；挂断只刷新消息，不额外调用模型。通话暂时关闭工具调用，避免主动搭话触发工具导致多轮请求。

此限制防止本页面的通话执行器并发重复生成，不是供应商计费保证。不同设备、手动重新回复/重试、已在云端执行的其他定时任务、供应商内部重试/扣费仍不由此队列控制。取消请求不能撤回已发生的供应商计费。已经开始执行的云端任务可能无法取消。

## 验证和发布

`npm run check:calls` 使用模拟模型与音频，验证队列上限、串行执行、挂断丢弃排队回复、自动搭话累计上限及可见性暂停、导航/缩小不重新挂载通话、最小化不打断语音。测试不发送收费请求。类型检查：`npx tsc --noEmit --incremental false`。完整生产构建：`npm run build`。

部署额度恢复后发布 GitHub main 的最新版本，再重启 Float。该通话功能的代码在网页端，不需要额外部署 iOS/Android 应用。实际 iPhone 麦克风、音量、页面布局、MiniMax 音色和长时间通话仍需真机验收；建议先关闭自动搭话，打一通短电话并在 Float 内逛朋友圈，再开启 1 次上限试用。
