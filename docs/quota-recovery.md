# 流量受限期间恢复聊天

设置 → 离线推送 → 手机内回复，开启后发送一条新消息，并保持 Float 在前台。
旧输入或已有云端提交记录的输入不会转到手机重复生成。首次收到明确的 Supabase 缓存出站超额 402 时会自动打开此模式，但不会重放当轮输入。

手机内回复只改变本机聊天生成位置，不解除 Supabase 限制，不恢复微信云助手或离线主动消息，也不免除模型 API 费用。

微信轮询使用独立的小包，只含 bot ID 和令牌，仍保存在原有受保护存储中。旧运行包在首次可用时自动创建小包；权限、配额、网络错误不会触发大包回退。完整运行包仅在收到新消息或待回复消息确实需要生成时加载，空闲和空队列自愈扫描不加载大包。核心协议升级到 8，避免动态加载旧核心抵消修复。
